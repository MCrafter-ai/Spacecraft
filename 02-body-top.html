Texture packs

Texture packs for this version ship as .epk files. Add one and it is stored in this browser, ready to pick before you launch. The bundled Default pack cannot be removed.

Mods

This build has no Java mod loader, so mods here are JavaScript files that run in the page a moment before the game boots — enough to change launch options, servers or page behaviour, not to add blocks or items. Only add files you trust: a mod can do anything this page can.
